Task List Screen


Users can be able to view a list of tasks to be completed.

For simplicity, I used the same hardcoded Task data models.

Users can be able to tap into a task and be navigated to the task detail screen.

Tasks that have been completed will be visually distinguished 


Task Detail Screen:

Users can be able to view the title, description, and possibly the attached photo of the task.

Users can be able to attach a photo to the task.

Attaching a photo will mark the task as completed with a visual indicator and shows the location of the photo inside of the map.

The completed indicator can also be visible in the task list.

In the task view Controller, the list page will reflect it was completed.
